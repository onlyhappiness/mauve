# mauve

macOS 화면 전체를 어항으로 삼아 물고기가 헤엄치는 아쿠아리움입니다. 일하는 동안 켜 두는 부담 없는 게임을 목표로 합니다.

> 개발 중인 프로젝트입니다.

## 특징

- **화면 전체 어항:** 주 모니터에서 메뉴 막대·Dock을 뺀 영역을 투명 창으로 덮고, 그 안을 물고기가 헤엄칩니다.
- **클릭 통과:** 모든 클릭이 뒤쪽 앱으로 넘어가 평소처럼 작업할 수 있습니다.
- **메뉴 막대 조작:** 메뉴 막대 아이콘의 메뉴로 조작합니다.
- **픽셀 아트 그림체.**

## 현재 구현된 것

- 화면 전체를 덮는 투명 창과 모든 클릭 통과
- 물고기 유영(개체마다 따로 움직이고 방향을 바꿈)
- 메뉴 막대 아이콘 메뉴: 항상 위에 표시, 물고기 보이기, 종료
- 진주·물고기·메뉴 설정 저장(백업 파일로 복구)
- 상점 패널(물고기 사고팔기). 화면에는 아직 띄우지 않습니다.

## 앞으로 만들 것

- 수초 배치, 화면 전체 상점, 물고기가 수초를 먹고 진주 받기
- 미니 복어·해파리·우파루파 등 물고기 추가
- 첫 실행 안내, 소리
- macOS 앱 내보내기, Windows 지원

## 실행 방법

필요한 것: macOS, [Godot](https://godotengine.org/) 4.7 이상

**터미널에서 실행**

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path <이 저장소 경로>
```

**Godot 에디터에서 실행**

1. Godot에서 이 폴더의 `project.godot`을 엽니다.
2. **Game** 탭의 ⋮ 메뉴에서 **Embed Game on Next Play**를 끕니다. 켜져 있으면 에디터 안에 게임이 들어가 투명 창을 확인할 수 없습니다.
3. ▶ 실행(`Cmd+B`)을 누릅니다.

종료는 메뉴 막대 아이콘 메뉴의 **종료**로 합니다.

## 프로젝트 구조

| 파일 | 역할 |
| --- | --- |
| `game.gd` | Autoload `Game`. 진주·보유 물고기·메뉴 설정과 저장 |
| `catalog.gd` | 물고기 종류 데이터(이름·가격·이미지·설명) |
| `save_data.gd` | 저장 파일 읽기·쓰기와 복구 |
| `screen/` | 시작 장면. 창 배치, 클릭 통과, 메뉴 막대 메뉴, 물고기 넣고 빼기 |
| `fish/` | 재사용할 물고기 장면 |
| `shop/` | 상점 패널 |
| `ui/` | 색·글꼴·UI 스타일 |
| `assets/` | 물고기·수초·UI 이미지와 글꼴 |

## 기술 메모

- Godot 4.7, GDScript, Compatibility 렌더러
- 클릭 통과는 `DisplayServer.window_set_mouse_passthrough()`에 넓이가 0인 다각형을 넘겨 모든 클릭이 뒤쪽 앱으로 가게 합니다. 빈 배열을 넘기면 반대로 창 전체가 클릭을 받습니다.
