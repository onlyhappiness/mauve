# mauve

macOS 데스크탑 한쪽에 작은 어항을 띄워 두고 물고기를 구경하는 아쿠아리움 위젯입니다. 일하는 동안 화면 구석에 켜 두는 부담 없는 게임을 목표로 합니다.

> 개발 중인 프로젝트입니다. 지금은 첫 시각 데모를 만들고 있습니다.

## 특징

- **데스크탑 위젯:** 테두리 없는 투명 창으로 어항만 화면 오른쪽 아래에 떠 있습니다.
- **클릭 통과:** 어항 바깥의 투명한 여백을 클릭하면 뒤쪽 앱이 그대로 반응합니다.
- **파스텔 그림체:** 크림색 테두리, 민트색 물, 살구색 금붕어.

## 현재 구현된 것

- 투명한 어항 창 (720×540, Retina 화면에서 약 360×270포인트)
- 어항 오른쪽 위 X 버튼으로 종료
- 어항 가운데에 물고기 한 마리 표시

## 앞으로 만들 것

첫 데모

- 물고기가 어항 안을 천천히 헤엄치며 방향을 바꾸기
- 추가 버튼으로 최대 5마리까지 늘리기
- 손잡이를 드래그해 창 옮기기
- 항상 위에 표시 켜고 끄기

이후

- 물고기·창 위치·설정 저장
- 게임 내 재화로 물고기·수초·어항 사고팔기
- 성장과 자동 수익
- Windows 지원

## 실행 방법

필요한 것: macOS, [Godot](https://godotengine.org/) 4.7 이상

**터미널에서 실행**

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path <이 저장소 경로>
```

**Godot 에디터에서 실행**

1. Godot에서 이 폴더의 `project.godot`을 엽니다.
2. **Game** 탭의 ⋮ 메뉴에서 **Embed Game on Next Play**를 끕니다. 켜져 있으면 에디터 안에 게임이 들어가 투명 창을 확인할 수 없습니다.
3. ▶ 실행(`Cmd+B`)을 누릅니다.

종료는 어항 오른쪽 위의 **X** 버튼으로 합니다.

## 프로젝트 구조

| 파일 | 역할 |
| --- | --- |
| `main.tscn`, `main.gd` | 시작 장면. 창 배치, 클릭 영역, 종료 버튼 |
| `aquarium.gd` | 어항 그리기와 어항 영역(`TANK_RECT`) 관리 |
| `fish.tscn`, `fish.gd` | 재사용할 물고기 장면 |

## 기술 메모

- Godot 4.7, GDScript, Compatibility 렌더러
- macOS에서 투명 창을 켜면 어항 위의 클릭까지 뒤쪽 앱으로 넘어가는 현상이 있었습니다. `DisplayServer.window_set_mouse_passthrough()`로 어항 영역만 클릭을 받도록 지정해 해결했습니다.
